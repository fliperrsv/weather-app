# Weatherly 2.0

Многофункциональное приложение для прогноза погоды с картой осадков, графиком температуры, поддержкой избранных городов, тёмной темой и переключением единиц измерения (°C/°F).

Приложение полностью адаптивно, работает на чистом HTML/CSS/JS и использует OpenWeatherMap API.

## 🔗 Живое демо

Посмотрите приложение в действии: [https://fliperrsv.github.io/weather-app/](https://fliperrsv.github.io/weather-app/)


## 📦 Основные возможности

- Текущая погода: температура, «ощущается как», скорость ветра, влажность.
- Прогноз на 5 дней с наглядным графиком температур (реализован с помощью Chart.js).
- Интерактивная карта осадков на базе Leaflet и OpenStreetMap.
- Функция геолокации: кнопка «Рядом со мной» для быстрого получения данных о погоде в текущем местоположении.
- Сохранение избранных городов в localStorage — ваши любимые локации всегда под рукой.
- Переключение между шкалами Цельсия (°C) и Фаренгейта (°F).
- Тёмная и светлая темы интерфейса (выбор сохраняется).
- Полностью адаптивный дизайн — удобно пользоваться как на десктопе, так и на мобильных устройствах.
- Анимация загрузки и продуманная обработка ошибок.

## 🛠 Используемые технологии

- **HTML5** — семантическая разметка для лучшей доступности и SEO.
- **CSS3** — использование переменных CSS, адаптивный дизайн, реализация тёмной темы.
- **JavaScript (ES6+)** — асинхронные запросы к API, работа с DOM, управление localStorage.
- **OpenWeatherMap API** — источник актуальных данных о погоде.
- **Chart.js** — построение графика температур.
- **Leaflet** — создание интерактивной карты осадков.

## 🧪 Как запустить локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/fliperrsv/weather-app.git
   cd weather-app
   ```
2. Откройте файл `index.html` в браузере либо запустите через локальный сервер.
3. Получите бесплатный API‑ключ на [OpenWeatherMap](https://openweathermap.org/api) и вставьте его в файл `script.js` в строке:
   ```javascript
   const API_KEY = '...';
   ```
4. Готово! Приложение полностью готово к работе в локальной среде.
